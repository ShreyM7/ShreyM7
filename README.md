## 📌 About Me
- I'm **Shrey**, an Electrical Engineering student at **McMaster University**.
- I like working on projects that combine **electronics, embedded systems, software, and robotics**. Most of what I build involves taking something from an idea or CAD model to a working system with sensors, microcontrollers, code, and hardware.
- I've worked on everything from **robotics research and autonomous systems to full-stack software**, and I'm currently part of the **McMaster Mars Rover Team**. I also like building personal projects and competing in hackathons.
- This is where I'll be sharing projects I've worked on, things I'm currently building, and experiments along the way.


## 🧠 My Focus Areas
- ⚡ Electrical & Embedded: PCB Design, ESP32, STM32, FPGA, Verilog, Arduino, Sensors, CAN, I2C, SPI, UART, Oscilloscope, Multimeter, Microcontroller, Soldering & Wiring
- 💻 Programming: ython, Java, C/C++, SQL, Linux, Git, REST APIs, CI/CD
- 🧰 Engineering Tools: KiCad, Altium, Cadence, SolidWorks, Autodesk Inventor, AutoCAD, Revit, MATLAB, Azure DevOps, Microsoft Azure, Microsoft Office, Microsoft Exce
